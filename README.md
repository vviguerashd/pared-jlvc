# Muro de TV · José Luis

Anteproyecto de Estudio Maderax: muro de TV con lambrín WPC, pintura en zona de TV, retorno nuevo con bastidor y dos repisas flotantes en L.

- `index.html`: página para el cliente (modelo 3D con three.js, plano acotado, acabados, inversión y siguientes pasos). Es un solo archivo; three.js se carga desde jsDelivr.
- `og-image.png`: vista previa para WhatsApp.

Publicado con GitHub Pages desde la rama `main`, carpeta raíz.
